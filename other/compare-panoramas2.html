Текущая пара городов

Радиус панорам

В каждом городе выбирается случайная точка около центра. Горизонтальный свайп поворачивает обе панорамы, вертикальная прокрутка переключает города. На компьютере нажмите «Экран 50/50», затем повторно нажимайте ту же кнопку в правом верхнем углу для циклического переключения: слева/справа → сверху/снизу → слева/справа. Каждая панорама займёт ровно половину экрана, угол обзора — 120°.

Радиус поиска точки3 км

Схема исходного приложения: Google Street View Service → panoId → снимок Google. Ключ вручную вводить не нужно. Доступность встроенного API зависит от браузера и Google; под каждым постом есть ссылки на открытие панорам в Google Maps.

⌖Определяем ближайший город по IP…

По IP определяется примерный район, без запроса GPS. Для этого браузер обращается к ipwho.is (при недоступности — к ipapi.co). Город можно изменить вручную.
